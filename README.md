# NIAP-BHS

A single-page web presentation covering ECAC Std. 3 EDS / HBS Level 2 baggage screening concepts, including the decision-window flow, threat-item reference imagery, and supporting documentation.

**Live site:** [https://engalixredha.github.io/NIAP-BHS/](https://engalixredha.github.io/NIAP-BHS/)

## Contents

## Usage

Open `index.html` in a browser, or visit the live GitHub Pages link above. No build step is required — everything runs client-side.

## Features

- Browser tab icon (favicon) generated from the CSCEC logo
- Link preview image (Open Graph / Twitter Card) shown when the site URL is shared
